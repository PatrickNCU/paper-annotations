# 手機是一塊遠端的螢幕，不是第二份筆記

1.23.0 讓 `serve.py` 綁得上 loopback 以外的位址，1.24.0 把書房頁做成手機上可用的樣子並加上「加到主畫面」。這兩件事合起來很容易被理解成「筆記上雲端了」，而它不是——這份 ADR 就是為了把那條界線寫死。

我們決定：**手機上不存任何筆記資料。** 它跑的是同一個頁面，打的是同一台電腦上的同一個 `serve.py`，寫的是同一份 `notes/reviews/`。手機不是一個副本，是一塊遠端的螢幕。

## Considered Options

- **把筆記同步到手機**（Syncthing、git、可同步資料夾的 Markdown 應用）：手機離線也看得到卡片。但評分寫不了——只有 server 能追加 `notes/reviews/`（ADR 0003）——所以同步過去的是一份**看得到卻答不了**的資料；而且從此有了兩份會分歧的東西，合併與衝突跟著進來。用最大的代價換最小的好處。
- **手機離線先記，連上再補送**：離線也能評分。但那份「還沒補送的評分」是不可重生的資料，存在手機瀏覽器的 localStorage 裡——清一次瀏覽資料就沒了，而使用者不會知道它沒了。ADR 0003 拒絕過同一件事，理由在這裡一字不改地成立。
- **把 server 放到雲端主機**：電腦關機也能用。但筆記從此離開他的磁碟，備份、隱私與「離線可開」三件事同時改變性質，而這套工具的唯一資料就是他自己的卡片。
- **手機只是遠端螢幕（採用）**：沒有副本、沒有合併、沒有衝突、沒有補送佇列——不是因為我們解得好，是因為那些問題從來沒有出現。代價寫在下面。

## Consequences

- **電腦沒開就什麼都沒有，而且畫面要直說。** 這是這個決定唯一的代價，也是它必須被看見的地方：書房頁連不到 server 時顯示「連不到電腦」，不是顯示一份舊的佇列。一個會給你昨天的卡、又記不了今天答案的 app，比一個誠實說自己離線的 app 更糟。
- **PWA 只快取外殼。** service worker 快取頁面與圖示，讓它開得快、開得起來；任何 `/_pa/` 的資料端點一律走網路，不進快取（`assets/sw.js`）。這條規則就是上一點的實作。
- **通道與其存取控制不屬於這個工具。** `--host` 收的只是一個位址，工具不認識 Tailscale，也不會去裝它、設定它或代管它的憑證。換成 ZeroTier、Netbird 或自架 WireGuard，同一行指令換個位址就能用。反過來說，通道壞了、帳號被盜，工具這邊什麼都不知道——所以還有金鑰那一層。
- **綁出 loopback 之後，每個請求都要金鑰，讀也要。** 預設綁 `127.0.0.1` 時「外面連不到」本身就是那道門；`--host` 是自己把門打開，所以要換一把鎖。讀也要擋，是因為他在問什麼、哪些還沒懂，並不比寫檔案的權限不敏感。
- **金鑰存在家目錄，不在 `papers.yml` 旁邊。** 登記簿跟著 git 走到別台機器，那是最不該放共用祕密的位置。金鑰重開 server 不換，否則手機主畫面的捷徑每次失效，換來的只是重打一次網址——而看得到這把金鑰的裝置本來就已經連得到這個位址。
- **裝成主畫面 app 需要 https。** 純 http 在 localhost 以外不是安全來源，service worker 註冊不起來。這不是工具修得了的事，所以 `serve.py` 啟動時直接說出來（`tailscale serve` 可以給一個），頁面則在不支援時安靜地不註冊，功能照常。
- **閱讀頁的觸控還沒做完。** 這一輪做的是複習動線：書房頁、今天要複習、卡片的分段揭示與評分。螢光筆、選取、畫記那一套仍是 roadmap 第 6 項，沒有假裝做完。
