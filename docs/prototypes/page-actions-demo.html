Chung-Kuan Cheng, Andrew B. Kahng, Ilgweon Kang, Lutong Wang · 2019

III. Local Density Function

ePlace uses a single density penalty factor for the entire placement region. This sacrifices the wirelength of bins with mild overlap in order to resolve bins with severe overlap. We introduce a local Lagrangian multiplier per bin, together with a per-instance coefficient.

The per-instance coefficient preserves part of the repulsive force for cells that have already escaped an overflowed bin, so that the force does not collapse the moment a cell crosses the bin boundary.

IV. Dynamic Step Size Adaptation

ePlace-MS already adapts the coefficient to maintain a fixed wirelength increment per iteration, but the adjustable range is hard-coded. RePlAce adapts the upper bound itself, using the wirelength curve obtained from a trial global placement.
