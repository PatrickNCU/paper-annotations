複習動線試玩

分段揭示的複習動線，用假資料玩一遍。

這在驗證什麼 「問題 → 先說有沒有把握 → 看一句話直覺（這時就能評分）→ 要的話再看完整解答 → 評分」這條路，加上答錯當天再來、半懂卡的出口、跨論文對照題和三種空狀態，操作起來順不順、有沒有哪一步你會覺得「不該是這樣」。 資料全是假的，評分只寫進右邊那個模擬的 notes/reviews/，重新整理就歸零。側欄與卡片面板照現在複習頁的樣子畫；這條灰帶、右邊的狀態欄，和頁面裡所有虛線框的字，都是試玩用的，不是工具的一部分。
