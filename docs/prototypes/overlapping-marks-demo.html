這在驗證什麼
  • 三種挑卡方式哪一種順手。也可以混搭，例如 A 的選單加上 C 的徽章。
  • 「跳到原文」：每張卡都有 ⤴，跳過去會把這張卡引的整句閃三下，不只閃重疊的那一段。沒有標記的卡（Q0109，引文是公式）改成閃它掛的整段。
  • 重疊處的顏色只分兩級：一張卡淺黃，兩張以上深黃，不隨張數一直加深。
  • 篩選時，一小段標記要等它所屬的卡全被篩掉才熄；只剩一張卡的地方點下去直接開卡。
