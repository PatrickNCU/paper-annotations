# 翻譯的預設規則

每篇論文都套用這幾條。書房的 LANGUAGES.md 與論文資料夾裡的 LANGUAGES.md 可以補充或改寫，越靠近論文的越優先。

- 自然的繁體中文，讀起來像中文寫的，不像逐字對譯。
- 每個術語只用它在這個領域實際被說的那一種形式：大家說英文的就留英文（placement、macro、benchmark），有通行中文的就用中文（線長、密度、迭代）。
- 不並列中英，不寫「巨集（macro）」這種括號。
- 縮寫照論文原本的寫法，論文在哪裡展開全名，譯文就在哪裡展開。
- 一段原文對一段譯文，不合併、不拆開、不調整順序；清單維持清單。
- 公式、變數、數字、單位、引用編號與註腳標記照抄原文。
- 圖、表、章節的稱呼保留論文的寫法（Fig. 1(a)、Table II、Section IV），方便對回原文。
- 只翻譯，不解說、不補充、不加強或減弱原文的語氣；看不懂的地方另外問，寫成疑問卡。
